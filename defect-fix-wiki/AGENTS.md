# Defect Fix Wiki Rules

This is a private LLM wiki for Multica defect-fix cases.

## Write Discipline

- `sources/` and `candidates/` may be generated by `scripts/defect-fix-wiki.mjs`.
- `wiki/` is the curated layer. Only the wiki-librarian workflow should move a candidate into `wiki/`.
- Do not commit private source records, candidate drafts, or curated case pages unless the target repository is explicitly approved for private wiki content.
- Public PR descriptions and issue comments must not cite private case IDs or private wiki URLs.

## MVP Commands

```bash
pnpm defect-fix-wiki init
pnpm defect-fix-wiki scan --repo multica-ai/multica --limit 50
pnpm defect-fix-wiki index
pnpm defect-fix-wiki lint
pnpm defect-fix-wiki query --text "runtime timeout" --module server
pnpm defect-fix-wiki trial --issue MUL-123 --result hit --query "runtime timeout" --cases pattern.runtime.timeout
pnpm defect-fix-wiki status
```

## Case Promotion

Before moving `candidates/pr-xxxx.candidate.md` into `wiki/`, verify:

- the user-visible symptom is grounded in the linked issue or PR,
- the root cause is explicit and not invented,
- the fix pattern is reusable beyond the exact diff,
- verification evidence is real,
- gotchas describe what should not be copied,
- private logs, tokens, cookies, and user secrets are absent.

## Query-Before-Fix Trials

Record each real issue pilot with `trial`. Use `--result hit` only when an
official case materially helped the investigation plan. Use `--result no_hit`
when no case applied. Trial records are private evidence and must not be cited
in public PRs or issue comments.
